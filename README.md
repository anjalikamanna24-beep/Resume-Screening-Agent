\# Resume Screening Agent



A Python-based Resume Screening Agent that analyzes resumes against a given job description and ranks candidates based on their matching skills and requirements.



\## Features



\- Extracts information from PDF resumes

\- Reads job description and requirements

\- Calculates a resume matching score

\- Ranks candidates based on their score

\- Generates a CSV file containing ranked candidates



\## Technologies Used



\- Python

\- PDF Resume Parsing

\- CSV

\- Regular Expressions
